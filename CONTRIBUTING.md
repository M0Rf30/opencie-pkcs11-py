Thank you for your interest in contributing to opencie-pkcs11-py! We welcome contributions from the community and appreciate your help in making this project better.

### Signing Your Commits

To certify your contributions, you must sign off on your commits using the `-s` flag with `git commit`:

```bash
git commit -s -m "Your commit message"
```

This will add a `Signed-off-by:` line to your commit message with your name and email address.

## Getting Started

1. Fork the repository
2. Create a feature branch for your changes
3. Make your changes and commit them with DCO sign-off
4. Push your branch and create a pull request

Thank you for contributing!
